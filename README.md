# LoadSail

LoadSail завантажує файли за прямими HTTP(S)-посиланнями й знаходить медіа у Windows 10/11. Розширення LoadSail для Firefox і Chrome передає вибрані файли та якість у чергу програми.

## Встановлення й оновлення

- **Pullora.** Відкрий `CpPrice11/ClipSail` у каталозі Pullora та встанови ZIP для Windows x64. Майбутні версії цієї копії з’являться в Pullora. Перед оновленням вийди з LoadSail через меню трея.
- **Окрема програма.** Запусти `LoadSail-…-windows-x64-setup.exe` з отриманого комплекту. LoadSail перевіряє оновлення під час запуску та кожні шість годин. Кнопка «Оновлення» у верхній панелі показує стан. «Оновити й перезапустити» завантажує нову версію, перевіряє підпис і запускає встановлення. Активні завантаження потрібно завершити або призупинити.

Якщо переходиш зі старого ZIP на інсталятор або Pullora, спочатку вийди зі старого ClipSail через трей. Обидва способи використовують наявну чергу й налаштування. Якщо LoadSail уже під’єднано до браузера, після запуску нової версії він оновить шлях до програми для Firefox і Zen.

## Запуск

### Portable

Розпакуй `LoadSail-…-windows-x64-portable.zip` у папку, куди можна записувати, і відкрий `LoadSail.exe`. Папка `data` містить чергу, галерею, налаштування та папку `Downloads` для нових завантажень. Для перенесення повністю вийди з LoadSail через трей і скопіюй усю папку програми. Якщо вибрав папку збереження поза нею, файли залишаться за тією адресою. Потрібен Microsoft Edge WebView2 Runtime.

Після перенесення Portable запусти LoadSail з нової папки. Він оновить недійсний шлях для Firefox і Zen. Якщо інша копія LoadSail уже підключена або потрібно підключити Chrome, вибери потрібний браузер у «Налаштування» → «Підключення браузерів».

### ZIP для Pullora

Щоб запустити ZIP вручну, розпакуй його повністю й відкрий `LoadSail.exe`. Файл `WebView2Loader.dll` має лежати поруч із програмою. Збірка розрахована на Windows x64 із Microsoft Edge WebView2 Runtime.

Хрестик ховає вікно в системний трей. Завантаження тривають, і розширення може передавати нові файли в чергу. Щоб повернути вікно, натисни іконку LoadSail біля годинника або ще раз відкрий `LoadSail.exe`. Щоб повністю закрити програму, клацни іконку правою кнопкою й вибери «Вийти з LoadSail».

Кнопка меню над іконками ліворуч розгортає назви розділів. У «Налаштуваннях» можна змінити мову інтерфейсу та папку збереження.

Для YouTube розпакуй також папку `tools`. LoadSail показує доступні MP4 без DRM. Якщо відео й звук доступні окремо, програма завантажує обидві доріжки та зберігає один MP4 через FFmpeg.

У комплекті [yt-dlp 2026.10.26](https://github.com/yt-dlp/yt-dlp/releases/tag/2026.10.26), [QuickJS-NG 0.18.0](https://github.com/quickjs-ng/quickjs/releases/tag/v0.18.0) і Windows-збірка [FFmpeg від FFmpeg-Builds](https://github.com/FFmpeg-Builds/FFmpeg-Builds/releases) зі спільними бібліотеками. Ліцензії та відомості про вихідний код FFmpeg лежать у папці `tools`.

## Пошук через плеєр

Встав посилання на сторінку й натисни «Знайти через плеєр». Запусти потрібне відео в окремому вікні. Коли LoadSail підтвердить відкритий записаний HLS або DASH, потік з’явиться в результатах пошуку. Щоб зберегти його, вибери результат і натисни «Завантажити».

## Пряме завантаження

У «Завантаженнях» натисни «Додати завантаження», встав адресу файлу й перевір посилання. Перед стартом видно назву, розмір за наявності та поточну папку. Після підтвердження завдання з’явиться в черзі. Для продовження після паузи натисни «Продовжити». Сервер має підтримувати завантаження частинами та підтвердити, що файл не змінився.

## Пошук медіа

Якщо звичайний пошук не знаходить відео на сторінці, LoadSail автоматично пробує вбудований yt-dlp. Для відкритих одиночних відео він показує сумісні якості в тому самому вікні. Черга запам’ятовує сторінку й вибрану якість та отримує свіжу адресу файла перед стартом і повторною спробою.

1. Встав адресу відкритої сторінки або пряме посилання на файл і натисни «Знайти».
   Для відео з X встав посилання на допис або на окремий ролик у ньому, наприклад із суфіксом /video/1. Програма покаже доступні прямі MP4 і дасть обрати якість.
   Для профілю або галереї познач «Шукати відео в дописах за посиланнями». LoadSail перевіряє відео в HTML і метаданих, посилання на дописи та наступні сторінки з позначкою `rel="next"`. За один пошук програма відкриває до 10 сторінок галереї й до 120 дописів та показує до 300 відео. Якщо сайт підвантажує наступні дописи лише після прокручування, результати залежать від посилань і метаданих у доступному HTML.
   У «Основних медіа» є окремі фільтри «Фото», «Відео» та «GIF». Іконки, емодзі та інші службові файли відкриваються через «Елементи сайту». Програма розпізнає їх за позначками й розмірами у вихідному коді сторінки.
   У «Додаткових фільтрах» можна вибрати розмір файлу, тривалість та роздільну здатність. Роздільну здатність фільтр визначає за коротшою стороною, тому однаково працює для вертикальних і горизонтальних файлів.
2. Натисни картку, щоб побачити збоку мініатюру й дані файла. Пробіл відкриває швидкий перегляд вибраного файла. Гортай файли стрілками ← → або натискай мініатюри під прев’ю. Прапорець «Позначити для завантаження» додає поточний файл до вибраних. Esc закриває швидкий перегляд.
   Відео запускається при відкритті прев’ю. Пряме відео відтворюється з посилання, а для YouTube використовується його вбудований плеєр. Якщо сайт обмежує вбудовування, натисни «Відкрити в YouTube».
3. Познач потрібні файли, за потреби зміни папку збереження й натисни «Завантажити вибране». Якщо є кілька якостей, LoadSail відкриє вибір із найвищою якістю за замовчуванням. Підтвердь кнопкою «Завантажити зараз».
4. У вкладці «Завантаження» стеж за прогресом. Після паузи або повторного запуску натисни «Продовжити».
5. У «Галереї» файли згруповано за датою збереження, а ширина мініатюр залежить від пропорцій файлів. Шукай за назвою, фільтруй за типом або переходь до потрібного періоду за шкалою праворуч. Клік відкриває відомості збоку, а пробіл запускає швидкий перегляд. Якщо вбудований плеєр не може відкрити файл, скористайся кнопкою «Відкрити через Windows». Видалення завершеного завдання з черги зберігає запис у галереї. Якщо перемістиш або видалиш сам файл, натисни «Оновити».
   Стрічка швидкого перегляду показує кадри збережених відео. Для YouTube кнопка «Перевірити іншу якість» шукає сумісні варіанти на джерелі. Якщо є вибір, «Завантажити копію» створює окреме завантаження в поточну папку.

Програма шукає прямі посилання у вихідному коді сторінки. Вона підтримує MP4, MOV, M4V, WebM, MKV, AVI, поширені формати зображень, MP3, M4A, WAV і Ogg. «Знайти через плеєр» також підхоплює прямі відео, які сторінка завантажує лише після запуску. Прямі відео зберігаються у вихідному форматі. Відтворення у вбудованому прев’ю залежить від підтримки формату й кодека у Windows WebView2. Розмір або роздільна здатність можуть бути невідомі, якщо джерело їх не надає. Картка «Відео · лише прев’ю» відкриває обкладинку вбудованого плеєра.

Відновлення прямих файлів із місця паузи й паралельне завантаження потребують підтвердження від сервера, що файл залишився тим самим. В інших випадках «Продовжити» починає завантаження з початку.

У «Знайти медіа» можна вставити адресу відкритого запису HLS або сторінки, яка оголошує потік у плеєрі. LoadSail показує доступні якості й зберігає вибрану у MP4. Якщо плеєр задав окремий звук, програма додає основну аудіодоріжку до відео. Після паузи або збою «Продовжити» використовує вже збережені частини, якщо список сегментів збігається. Підтримуються записи без шифрування із сегментами MPEG-TS або fMP4. Для збереження потрібен FFmpeg із папки `tools`. Користувач відповідає за дотримання правил сайту й авторських прав.

Для відкритого запису DASH встав адресу MPD або сторінки, яка оголошує цей потік. Підтримуються статичні записи з одним періодом і сегментами fMP4. LoadSail зберігає вибрану якість разом з основною аудіодоріжкою та зберігає прогрес між спробами, поки список сегментів збігається.

## Firefox і сайти з входом

1. У LoadSail відкрий «Налаштування» → «Підключення браузерів» і перейди за посиланням [«Розширення Firefox у Mozilla Add-ons»](https://addons.mozilla.org/firefox/addon/clipsail-video/). Відкрий сторінку у Firefox і натисни «Додати до Firefox».
2. Під час встановлення підтвердь доступ до вебсайтів. Відкрий сайт у звичайній вкладці Firefox і ввійди, якщо він потребує входу.
3. Запусти LoadSail, щоб він автоматично підключився до Firefox. Коли панель розширення покаже «LoadSail підключено», увімкни передачу у Windows. Якщо доступ до сайтів вимкнено, скористайся кнопкою «Дозволити доступ до всіх сайтів» і підтвердь запит Firefox.
4. Натисни іконку завантаження біля плеєра. Найвища доступна якість стоїть першою. Натискання на рядок якості одразу запускає завантаження в налаштовану папку.
5. Окремі фото, відео, аудіо й вибрані файли з панелі розширення також потрапляють у чергу LoadSail. Використовуй розширення 0.1.18 і програму 0.1.23 або новіші. Якщо плеєр ще не завантажив пряме відео, спочатку натисни Play.

Розширення передає адресу файла, джерело та якість програмі на цьому ПК. Cookies і паролі залишаються в браузері, тому джерела, які вимагають браузерної сесії для самого файла, можуть повертати відмову. Потрібна звичайна вкладка. LoadSail відхиляє виявлений DRM.

Вимкнення згоди в панелі зупиняє передавання нових завдань у LoadSail.

## Chrome

Потрібен LoadSail для Windows 0.1.27 або новіший.

1. Розпакуй `LoadSail-0.1.19-chrome.zip` у постійну папку.
2. У Chrome відкрий `chrome://extensions`, увімкни «Режим розробника», натисни «Завантажити розпаковане розширення» й вибери папку з `manifest.json`.
3. У LoadSail відкрий «Налаштування» → «Підключення браузерів» → «Під’єднати Chrome». У панелі розширення один раз увімкни передавання в LoadSail.
4. Перезавантаж вкладку. Натисни іконку завантаження біля плеєра, а потім рядок потрібної якості. Файл піде в чергу LoadSail.

Тестова збірка встановлюється вручну. Для збірки з коду виконай `pwsh -File scripts/package-chrome.ps1`. Файли розширення з’являться в `release/chrome`.

## Збірка з коду

Потрібні Rust, Microsoft C++ Build Tools і WebView2. З кореня вихідного коду виконай `cargo build --locked --bins --release --features tauri/custom-protocol`. Застосунок і локальний компонент Firefox з’являться в `target/release`. Залиш обидва EXE в одній папці.

Для YouTube поклади офіційні `yt-dlp.exe` і `qjs-windows-x86_64.exe` у папку `tools` поруч зі зібраним EXE. Назви файл QuickJS `qjs.exe`.

Інтерфейс працює в Tauri 2. Rust аналізує сторінки, завантажує медіа і зберігає локальну чергу. Візуальні зразки та палітра зазначені в `ui/assets-note.txt`.
