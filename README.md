# ClipSail

ClipSail зберігає фото, відео й аудіо у Windows 10/11. Розширення для Firefox і Zen передає вибрані файли та якість у чергу програми.

## Встановлення й оновлення

- **Pullora.** Відкрий `CpPrice11/ClipSail` у каталозі Pullora та встанови ZIP для Windows x64. Майбутні версії цієї копії з’являться в Pullora. Перед оновленням вийди з ClipSail через меню трея.
- **Окрема програма.** Запусти `ClipSail-…-windows-x64-setup.exe` з [GitHub Releases](https://github.com/CpPrice11/ClipSail/releases/latest). ClipSail перевіряє оновлення під час запуску та кожні шість годин. Кнопка «Оновлення» поруч із вибором мови показує стан. «Оновити й перезапустити» завантажує нову версію, перевіряє підпис і запускає встановлення. Активні завантаження потрібно завершити або призупинити.

Якщо переходиш зі старого ZIP на інсталятор або Pullora, спочатку вийди зі старого ClipSail через трей. Обидва способи використовують наявну чергу й налаштування. Якщо ClipSail уже під’єднано до браузера, після запуску нової версії він оновить шлях до програми для Firefox і Zen.

## Запуск

Щоб запустити ZIP вручну, розпакуй його повністю й відкрий `ClipSail.exe`. Файл `WebView2Loader.dll` має лежати поруч із програмою. Збірка розрахована на Windows x64 із Microsoft Edge WebView2 Runtime.

Хрестик ховає вікно в системний трей. Завантаження тривають, і розширення може передавати нові файли в чергу. Щоб повернути вікно, натисни іконку ClipSail біля годинника або ще раз відкрий `ClipSail.exe`. Щоб повністю закрити програму, клацни іконку правою кнопкою й вибери «Вийти з ClipSail».

Для YouTube розпакуй також папку `tools`. ClipSail показує доступні MP4 без DRM. Якщо відео й звук доступні окремо, програма завантажує обидві доріжки та зберігає один MP4 через FFmpeg.

У комплекті [yt-dlp 2026.10.26](https://github.com/yt-dlp/yt-dlp/releases/tag/2026.10.26), [QuickJS-NG 0.18.0](https://github.com/quickjs-ng/quickjs/releases/tag/v0.18.0) і Windows-збірка [FFmpeg від FFmpeg-Builds](https://github.com/FFmpeg-Builds/FFmpeg-Builds/releases) зі спільними бібліотеками. Ліцензії та відомості про вихідний код FFmpeg лежать у папці `tools`.

1. Встав адресу відкритої сторінки або пряме посилання на файл і натисни «Знайти».
   Для профілю або галереї познач «Шукати відео в дописах за посиланнями». ClipSail перевіряє відео в HTML і метаданих, посилання на дописи та наступні сторінки з позначкою `rel="next"`. За один пошук програма відкриває до 10 сторінок галереї й до 120 дописів та показує до 300 відео. Якщо сайт підвантажує наступні дописи лише після прокручування, результати залежать від посилань і метаданих у доступному HTML.
   У «Основних медіа» є окремі фільтри «Фото», «Відео» та «GIF». Іконки, емодзі та інші службові файли відкриваються через «Елементи сайту». Програма розпізнає їх за позначками й розмірами у вихідному коді сторінки.
   У «Додаткових фільтрах» можна вибрати розмір файлу, тривалість та роздільну здатність. Роздільну здатність фільтр визначає за коротшою стороною, тому однаково працює для вертикальних і горизонтальних файлів.
2. Натисни картку, щоб побачити збоку мініатюру й дані файла. Пробіл відкриває швидкий перегляд вибраного файла. Гортай файли стрілками ← → або натискай мініатюри під прев’ю. Прапорець «Позначити для завантаження» додає поточний файл до вибраних. Esc закриває швидкий перегляд.
   Відео запускається при відкритті прев’ю. Пряме відео відтворюється з посилання, а для YouTube використовується його вбудований плеєр. Якщо сайт обмежує вбудовування, натисни «Відкрити в YouTube».
3. Якщо на картці відео є «Якість завантаження», можеш вибрати іншу роздільність. Спочатку вибрана найвища з доступних. За потреби зміни папку збереження й натисни «Завантажити вибране».
4. У вкладці «Завантаження» стеж за прогресом. Після паузи або повторного запуску натисни «Продовжити».
5. У «Галереї» файли згруповано за датою збереження, а ширина мініатюр залежить від пропорцій файлів. Шукай за назвою, фільтруй за типом або переходь до потрібного періоду за шкалою праворуч. Клік відкриває відомості збоку, а пробіл запускає швидкий перегляд. Якщо вбудований плеєр не може відкрити файл, скористайся кнопкою «Відкрити через Windows». Видалення завершеного завдання з черги зберігає запис у галереї. Якщо перемістиш або видалиш сам файл, натисни «Оновити».
   Стрічка швидкого перегляду показує кадри збережених відео. Для YouTube кнопка «Перевірити іншу якість» шукає сумісні варіанти на джерелі. Якщо є вибір, «Завантажити копію» створює окреме завантаження в поточну папку.

Програма шукає прямі посилання у вихідному коді сторінки. Вона підтримує поширені формати зображень, MP4, WebM, MP3, M4A, WAV і Ogg. Розмір або роздільна здатність можуть бути невідомі, якщо джерело їх не надає. Прев’ю відео використовує обкладинку зі сторінки, якщо вона доступна. Картка «Відео · лише прев’ю» відкриває обкладинку вбудованого плеєра.

Відновлення з місця паузи й паралельні частини потребують підтвердження від сервера, що файл залишився тим самим. В інших випадках «Продовжити» починає з початку. HLS/DASH і вибір якості потоку заплановані окремим етапом. Користувач відповідає за дотримання правил сайту й авторських прав.

## Firefox і сайти з входом

1. Для тестування до публікації відкрий у Firefox `about:debugging#/runtime/this-firefox`. Натисни «Завантажити тимчасовий додаток» і вибери `firefox/manifest.json` із розпакованого архіву. Після перезапуску Firefox завантаж тимчасовий додаток знову.
2. Під час встановлення підтвердь доступ до вебсайтів. Відкрий сайт у звичайній вкладці Firefox і ввійди, якщо він потребує входу.
3. У ClipSail для Windows відкрий «Завантаження» та натисни «Під’єднати Firefox / Zen». У панелі розширення вибери «Дозволити передачу в ClipSail для Windows». Повтори під’єднання, якщо перемістиш розпаковану програму.
4. Натисни «Завантажити це відео» біля плеєра. Найвища доступна якість стоїть першою. Натискання на рядок якості одразу запускає завантаження в налаштовану папку.
5. Окремі фото, відео, аудіо й вибрані файли з панелі розширення також потрапляють у чергу ClipSail. Використовуй розширення 0.1.18 і програму 0.1.23 або новіші. Якщо плеєр ще не завантажив пряме відео, спочатку натисни Play.

Розширення передає адресу файла, джерело та якість програмі на цьому ПК. Cookies і паролі залишаються в браузері, тому джерела, які вимагають браузерної сесії для самого файла, можуть повертати відмову. Потрібна звичайна вкладка. ClipSail відхиляє виявлений DRM. Загальні HLS і DASH потребують окремої підтримки.

Вимкнення згоди в панелі зупиняє передавання нових завдань у ClipSail.

## Збірка з коду

Потрібні Rust, Microsoft C++ Build Tools і WebView2. З кореня вихідного коду виконай `cargo build --locked --bins --release --features tauri/custom-protocol`. Застосунок і локальний компонент Firefox з’являться в `target/release`. Залиш обидва EXE в одній папці. Команда `cargo test --locked` перевіряє пошук медіа, відносні посилання, імена файлів Windows і формат повідомлень Firefox.

Для YouTube поклади офіційні `yt-dlp.exe` і `qjs-windows-x86_64.exe` у папку `tools` поруч зі зібраним EXE. Назви файл QuickJS `qjs.exe`.

Інтерфейс працює в Tauri 2. Rust аналізує сторінки, завантажує медіа і зберігає локальну чергу. Візуальні зразки та палітра зазначені в `ui/assets-note.txt`.
